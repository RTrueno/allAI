Это готовое содержимое репозитория RTrueno/allAI.

1. Нажми правой кнопкой на allAI-ready-to-upload.zip → «Извлечь всё».
2. Открой распакованную папку. В ней должны быть README.md, package.json и папки app, desktop, docs, .github.
3. В GitHub открой RTrueno/allAI → Add file → Upload files.
4. Загрузи содержимое распакованной папки, сохраняя структуру. Не загружай сам ZIP и не загружай папку outputs.
5. Если GitHub не принимает все файлы за раз, загружай папки по очереди; скрытую .github можно добавить отдельно через Add file → Create new file, указав имя .github/workflows/desktop.yml и скопировав содержимое из распакованного файла. Проверь наличие также .gitignore, .env.example и .npmrc.
6. Если GitHub предлагает замену README.md — замени его файлом из этого архива. Ссылки в нём уже настроены на RTrueno/allAI.

Файлы архива ZIP сами по себе GitHub не распаковывает.

После загрузки в репозитории должны открываться:
- desktop/assets/icon.png — логотип;
- docs/preview.jpg — скриншот;
- desktop/README.md — инструкция клиента;
- .github/workflows/desktop.yml — сборка всех платформ.

Установщики EXE размещай в Releases: создай выпуск с тегом v1.0.0 и прикрепи файлы setup.exe и portable.exe. До этого ссылки на скачивание в README будут вести на ещё не созданный выпуск.
