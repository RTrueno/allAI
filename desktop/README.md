# allAI Desktop

Десктопный клиент allAI на Electron для Windows, macOS и Linux. Приложение открывает опубликованную веб-версию в отдельном изолированном окне. Для чатов нужен интернет. Аккаунт и серверные диалоги общие с сайтом.

## Возможности

- Отдельное окно с иконкой, навигацией, обновлением и открытием сайта в системном браузере.
- Каталог нейросетей, пользовательские ключи OpenRouter, смена модели с историей и сообщество через веб-версию.
- Сохранение сессии входа, размера и положения окна между запусками; один экземпляр приложения.
- Экран повторного подключения при сетевой ошибке.
- Изолированный веб-контент: sandbox, отключённый Node.js, без preload и без доступа к файловой системе.
- Ключи не встроены в приложение. Пользовательский ключ хранится в памяти страницы и после перезапуска вводится заново.

Сайт пока приватный: для доступа нужен разрешённый аккаунт Sites/ChatGPT. Установка приложения не расширяет доступ. Google и другие провайдеры могут ограничивать вход через встроенные браузеры: в таком случае используй вход по почте. Кнопка «Открыть в браузере» открывает веб-версию; сессия системного браузера не переносится в приложение автоматически.

## Локальный запуск

Нужен Node.js 22.13 или новее.

```sh
cd desktop
npm ci
npm start
```

В корне веб-проекта доступны те же команды через `npm run desktop:dev` после установки зависимостей desktop.

## Сборки

Выполняй команды в папке `desktop` на соответствующей ОС:

```sh
npm run dist:win
npm run dist:mac
npm run dist:linux
```

Результат — в `desktop/release`:

| Система | Формат |
| --- | --- |
| Windows x64 | Установщик `.exe` с ярлыками и portable `.exe` |
| macOS Apple Silicon / Intel | `.dmg` и `.zip` с `.app` |
| Linux x64 | `.AppImage` и `.deb` |

Готовые Windows-сборки можно запускать без Node.js и без установки зависимостей. Для macOS и Linux предусмотрена нативная сборка через GitHub Actions.

## Сборка через GitHub

Загрузи весь проект с папками `desktop` и `.github` в корень репозитория. Открой **Actions → Desktop builds → Run workflow**. После завершения скачай нужную сборку из **Artifacts**. Workflow также запускается при изменении desktop-файлов в main/master. Он не публикует релизы и не требует API-ключей моделей.

По умолчанию сборки не подписаны. Для распространения без предупреждений ОС настрой сертификат подписи Windows; для macOS — Developer ID и notarization. Учётные данные подписи хранятся в секретах CI. В этом проекте они не заданы, выдача подписанной сборки не подтверждена.

## Проверки

```sh
npm test
npm run test:smoke
```

Первая команда проверяет ограничения навигации, внешних ссылок и восстановление окна. Вторая запускает приложение, проверяет загрузку удалённой страницы и изоляцию окна, затем закрывает его; нужен доступ к сайту. Проверка страницы входа не подтверждает вход в аккаунт или успешный запрос к AI-модели.

Исходный URL сайта задан в `policy.cjs`; меняй его только на свой доверенный HTTPS-домен. Произвольного поля URL в приложении нет. Обновления веб-интерфейса появляются при перезагрузке; автоматическое обновление самого Electron-клиента пока не подключено.
